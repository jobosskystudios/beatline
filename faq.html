FAQ

Is my music uploaded anywhere?

No. Decoding, analysis and export all happen inside your browser tab. Only your settings (frame rate, folder path…) are remembered, in this browser.

The tempo is double (or half) what it should be.

Very common with half-time beats. Press ½× or 2×, or type the BPM you know into the tempo box.

The markers feel slightly early or late.

Use Nudge all markers (a few tens of ms is typical), or change Snap to frame to Previous or Next. Cutting a frame before the beat often feels tighter on screen.

The song has a live drummer / tempo changes.

Lower Grid strictness so the grid can drift with the band. For music with no steady pulse, switch to Hits.

Final Cut says the media is missing.

The path you typed doesn’t match where the song is. Select the clip and choose File › Relink Files…, or re-export with the correct folder. Spaces and special characters in names are fine.

Final Cut won’t import the file.

Pick an older FCPXML version under More export options (1.9 works with Final Cut Pro 10.5 and later). If it still fails, please open an issue with the FCP version and the error text.

Which frame rate should I choose?

The frame rate of the Final Cut project you’ll cut in — check it in the project’s Inspector (Modify › Project Properties). Markers are snapped to that rate’s frames.

Final Cut Pro 12 has beat detection built in. Why use this?

If FCP’s built-in grid does what you need, use it! Beatline adds bar-aware labels, density choices (every bar, every 2 or 4 bars), hit detection, hand editing with a metronome check, frame-snapping control, and it works with older FCP versions.

Can I use the markers in Premiere Pro or DaVinci Resolve?

Download the .csv marker list — it has seconds, frame numbers and timecode for each marker. Resolve can also import FCPXML; how it treats the markers depends on the Resolve version.

Which browsers work?

Current Safari, Chrome, Edge and Firefox on macOS. FLAC decoding depends on the browser; WAV and AIFF are the safest.

Can I use it offline?

Yes — clone or download the repository and run python3 -m http.server in its folder, then open http://localhost:8000. There are no dependencies.
